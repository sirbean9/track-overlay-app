# Track Overlay

Lap timing, sector splits and telemetry drawn onto your GoPro track-day footage. Free for macOS and Windows.

**Website:** https://sirbean9.github.io/track-overlay-app/

## Download

The first release is coming soon. Downloads will be on [Releases](https://github.com/sirbean9/track-overlay-app/releases/latest):

| File | For |
|---|---|
| `TrackOverlay-mac-arm64.zip` | Macs with Apple silicon, macOS 12 or later |
| `TrackOverlay-mac-x64.zip` | Intel Macs, macOS 10.15 or later |
| `TrackOverlay-win-x64.zip` | Windows 10 or 11, 64-bit |

Needs a GoPro HERO5 or newer with GPS on.

The builds aren't code-signed yet. On a Mac, right-click the app and choose **Open** the first time. On Windows, click **More info**, then **Run anyway**.
